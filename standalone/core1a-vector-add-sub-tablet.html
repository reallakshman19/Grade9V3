Learning promise

By the end of this concept book, you should be able to move deliberately between arrows and signed components without losing direction information.

  • add vectors by corresponding signed components;
  • translate a requested resultant direction into a component constraint;
  • explain why swapping A − B to B − A reverses a non-zero result;
  • resolve a magnitude-and-angle vector into signed perpendicular components;
  • recognise where this vector work stops and Motion-in-2D dynamics begins.

Before you start

You need signed coordinates, basic right-triangle sine/cosine ratios, and the idea that a vector has both magnitude and direction.

Model contract

  • Declare one perpendicular x–y axis system.
  • Keep every vector in that same basis while combining it.
  • Component signs come from the declared positive directions.
  • Sine/cosine produce projection magnitudes only after the angle reference is known.
  • Vector decomposition is a representation change, not a time-evolution law.

MIC-PHY-VEC-COMPONENT-SUM

Add vectors by corresponding signed components

The inferential jump is simple but important: vector addition preserves direction by combining each axis independently. Adding magnitudes alone destroys that information unless the vectors happen to be collinear in the same direction.

Arrow view
Tail-to-head geometry gives one resultant arrow. Its direction matters as much as its length.
Component view
A = (Aₓ,Aᵧ), B = (Bₓ,Bᵧ). Each signed number tells how much of that vector lies along one declared axis.
Declare one frame.
Why valid: corresponding components only mean the same thing when both vectors use the same axes and positive directions.
Add x with x and y with y.
Why valid: a common basis separates the two perpendicular contributions.
Read the resultant signs.
Why valid: the sign pair tells the quadrant/direction of the resultant before any magnitude is calculated.
A + B = (Aₓ + Bₓ, Aᵧ + Bᵧ)

Common wrong idea

“The magnitude of A + B is always |A| + |B|.”

Rebuild it: equal opposite vectors have non-zero magnitudes but add to the zero vector. Keep signed components or the arrow geometry until the resultant is known.

Concept companion

Words
component · basis · resultant · signed direction

Self-explain

  • Why must x-components never be directly added to y-components?
  • If A = (3,4) and B = (−5,2), predict the signs of A+B before calculating.

Boundary check

If B = −A, every corresponding component cancels; the result is the zero vector.

MIC-PHY-VEC-RESULTANT-CONSTRAINT

Turn a requested resultant direction into a component condition

Sometimes you are not asked to “find the resultant.” Instead, a direction of the resultant is specified and one input must be chosen to make that direction possible. The direction statement becomes an equation.

Translate the requested direction.
Example: a resultant exactly along +y has Rₓ = 0. The condition belongs to the resultant, not automatically to either input.
Write the component sum on that axis.
Rₓ = Aₓ + Bₓ gathers every x contribution with its sign.
Solve the compensating input component.
If Rₓ = 0 and Bₓ = +3, then Aₓ must be −3.
Substitute back.
0 = (−3) + (+3) independently checks the sign and the chosen axis.
Rₓ = Aₓ + Bₓ; if Rₓ = 0, then Aₓ = −Bₓ

Common wrong idea

“For a resultant to point straight across, each input vector must point straight across.”

Rebuild it: individual vectors may have opposite along-axis components that cancel. The direction requirement constrains the sum.

Concept companion

Decision
Which resultant component is fixed by the direction statement?

Quick check

If the resultant has x-component zero but y-component +5, is the resultant the zero vector? No. One component can be zero while the vector remains non-zero.

Motion link

This same component-cancellation idea later appears in relative-motion stories. The vector route owns the component condition; later motion belongs to its own model.

MIC-PHY-VEC-SUB-ORDER

Operand order reverses a non-zero subtraction result

A − B and B − A use the same two vectors but ask for opposite directed differences. The length is the same; the orientation reverses, except at the zero-vector boundary.

A − B
Think A + (−B): reverse B, then add tail-to-head.
B − A
Think B + (−A): reverse A instead. The completed result points exactly opposite.
B − A = −(A − B)
Keep A and B fixed.
That isolates operand order as the only change.
Construct one order.
Use the known graphical subtraction rule: add the negative of the second vector.
Swap only the order and compare from one start.
Superposition makes the reversal visible: same magnitude, opposite direction.

Common wrong idea

“Vector subtraction is commutative, just like vector addition.”

Rebuild it: addition can swap operands without changing the sum, but subtraction encodes an ordered directed difference.

Concept companion

Boundary case
If A = B, both A−B and B−A are the zero vector. A zero vector has no direction to reverse.

Predict first

If A−B points southeast, where must B−A point? Northwest.

Check

Swap the labels a second time. You must return to the original direction without changing the length.

MIC-PHY-VEC-ANGLE-DECOMPOSITION

Resolve a magnitude-and-angle vector into signed perpendicular components

A vector drawn as one arrow and the same vector written as two signed components are equivalent representations. Projection changes representation; it does not tell you how the vector changes later in time.

Decide whether decomposition is needed.
If the vector is already given as signed components, another sine/cosine conversion is unnecessary.
Declare axes and the angle reference.
“30° from +x” and “30° from +y” assign adjacent/opposite legs differently.
Name adjacent and opposite before sine/cosine.
Cosine belongs to the adjacent projection and sine to the opposite projection; x/y labels come only after the geometry is fixed.
Project magnitudes, then attach signs.
Trigonometry gives non-negative leg lengths for the acute reference triangle; the coordinate directions provide signs.
Bind the physical role and verify.
For launch velocity, call the initial pair uₓ,uᵧ. Recombine the components to check the original magnitude and quadrant.
V_adj = V cos θ;   V_opp = V sin θ
20 at 30° above +x
Vₓ = 20 cos30° = 10√3
Vᵧ = 20 sin30° = 10
12 at 30° right of +y
Vᵧ = 12 cos30° = 6√3
Vₓ = 12 sin30° = 6

Common wrong idea

“x is always V cosθ.”

Rebuild it: ask which axis the angle is measured from. Cosine follows the adjacent leg, not the letter x.

Second wrong idea

“After resolving a launch velocity, uₓ and uᵧ are automatically the later velocity components.”

Rebuild it: decomposition describes the initial vector only. A later vₓ or vᵧ requires the relevant Motion‑in‑2D acceleration model.

Concept companion

Projection
representation conversion, not a new force or motion law

Three checks

  • √(Vₓ²+Vᵧ²) reconstructs V.
  • Signs place the vector in the intended quadrant.
  • A small angle from an axis gives the larger adjacent component.

Stop line

This Core1A route stops after signed component representation. Dot/cross products and later-time dynamics belong elsewhere.

WATCH ONE · Add components without losing direction

In one east-positive, north-positive frame, let A=(3,4) and B=(−5,2). Find A+B and interpret its direction.

STEP
WHY THIS STEP
WORKING
1 · Fix the frame
Signs only have meaning relative to declared positive directions.
+x east; +y north.
2 · Add x with x
Horizontal contributions combine independently of vertical contributions.
Rₓ=3+(−5)=−2.
3 · Add y with y
Keep the same common basis.
Rᵧ=4+2=6.
4 · Interpret signs
Components are directional information, not just numbers.
A+B=(−2,6): westward and northward.
5 · Check geometrically
Independent representation should agree.
A tail-to-head sketch should finish left of and above the start.

Easy mistake to make

Turning −5 into +5 because it is a “magnitude”, then obtaining (8,6).

Repair: the input here is a signed component, not an unsigned vector magnitude. Keep its sign through component addition.

Faded practice · teaching is complete, now reduce support

Try one with support

A current contributes +3 along x. Choose a swimmer x-component so the combined velocity has x-component 0.

Start: write the target first: Rₓ = 0. Then fill the sum.

Model response: 0 = vₛ,ₓ + 3, so vₛ,ₓ = −3. Substitute: (−3)+3=0.

Try one yourself

A vector has magnitude 18 and points 25° below +x. Resolve it into signed components.

Model response: Vₓ=+18cos25°, Vᵧ=−18sin25°. The magnitude reconstructs to 18 and the sign pair is quadrant IV.

Boundary check

A velocity is already given as v=(−6 i + 8 j) m/s. Must you perform magnitude-angle decomposition before using these components?

Model response: No. The vector is already in signed component form. A useful check is |v|=√(36+64)=10 m/s.

Self-explain

A−B points southeast. Without recomputing its length, describe B−A and state the boundary case where “opposite direction” no longer has meaning.

Model response: B−A points northwest with the same magnitude. If A=B, both differences are the zero vector, which has no direction to reverse.
