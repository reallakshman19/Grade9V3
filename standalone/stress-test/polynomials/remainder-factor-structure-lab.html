1. Set the mathematical state

Inputs accept integers or exact fractions such as 3/2. Decimals are intentionally rejected.

2. Predict before calculating

Do you expect the linear divisor to be a factor of P(x)?

What to look for

  1. Predict: choose a structural expectation before seeing the computed remainder.
  2. Manipulate: change coefficients and divisor parameters using exact rational values.
  3. Observe: after commitment, compare evaluation conditions with the division remainder.
  4. Explain: decide which relationship survives as the examples change.
  5. Formalise: connect the pattern to P = DQ + R and deg R < deg D.
  6. Apply: use the invariant to avoid unnecessary long division when the source question warrants it.
