⚡ Core Mole Formulas

• n = mass / Molar mass = m / M
• n = N / N_A  (N_A = 6.022 × 10²³)
• n = V_STP / 22.4 L
• Molarity (M) = moles solute / Volume solution (L)
• Molality (m) = moles solute / mass solvent (kg)
• Mole Fraction x_A = n_A / (n_A + n_B)
• Mass % = (mass solute / mass solution) × 100
