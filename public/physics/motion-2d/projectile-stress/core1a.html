CORE1A · Completed construction

Full declarative teaching for the canonical three microtopics and all five researched extensions.

Sequence

Canonical R1–R3 is taught first. The five extension lessons follow and are visibly marked. The default 50% learner estimate does not reduce intrinsic teaching depth.

Canonical teaching

CANONICALMEDIUM

Split one plane-motion event into independent x/y components with one clock

Entry assumptions: Can read signed vector components in a declared x-y frame.

Inferential jump: Perpendicular components may be solved separately because each axis equation contains only that axis's quantities, but they still describe one object at one physical time.

Shared-clock representation: component values form one state only when they refer to the same instant.

Completed construction

K2D1-1 · DECLARE

Choose one fixed x-y frame, one origin and one time origin for the whole plane-motion event.

Why valid: A component value is meaningful only after its frame and sign convention are fixed.

Output: one declared frame, origin, axis orientation and t=0

K2D1-2 · TRANSFORM

Represent position, velocity and acceleration as signed x and y components in that same frame.

Why valid: A plane vector is completely represented by its perpendicular Cartesian components once the frame is declared.

Output: signed component state (x,y), (v_x,v_y), (a_x,a_y)

K2D1-3 · TRANSFORM

Keep x-quantities in the x description and y-quantities in the y description while using one shared elapsed time.

Why valid: The perpendicular component equations are independent in Cartesian kinematics, but both describe the same object during the same physical interval.

Output: two axis histories coupled by one clock

K2D1-4 · VERIFY

Recombine only component values that refer to the same frame and the same instant.

Why valid: Mixing x at one time with y at another does not describe any single physical state of the object.

Output: one physically valid plane state reconstructed from simultaneous components

Worked conceptual anchor / exit

A particle has x-velocity 6 m/s and y-velocity -8 m/s at t=3 s. Explain what 'independent components' means and what must remain shared between the x and y descriptions.

Model response: The x and y component equations are solved separately in the same frame, but both describe the same particle at the same t=3 s.

Plausible wrong path

Independent x and y motions may use different elapsed times.

Diagnose: At one instant 2 s after launch, may the x equation use t=2 s while the y equation uses another time?

Repair: No. Independence separates the axis equations; it does not give the same object two clocks.

Independent check / boundary

If a_x=0 but a_y is nonzero, may v_x stay constant while v_y changes?

Yes. That is exactly what independent component evolution permits. — One component can change while the other does not.

CANONICALMEDIUM

Apply constant-acceleration kinematics component by component

Entry assumptions: Can use the existing one-dimensional constant-acceleration model. · Can keep x/y components separate with one common time.

Inferential jump: The one-dimensional constant-acceleration equations can be applied to each perpendicular component independently when a_x and a_y are each constant over the same interval.

Shared-clock representation: component values form one state only when they refer to the same instant.

Completed construction

K2D2-1 · DECLARE

Check separately whether a_x and a_y are constant over the interval before choosing constant-acceleration equations on either axis.

Why valid: The familiar one-dimensional kinematic relations are exact only on an axis whose acceleration component is constant over the interval.

Output: per-axis model-validity decision

K2D2-2 · TRANSFORM

Apply the one-dimensional constant-acceleration relations independently to x and y using only that axis's signed values and the same t.

Why valid: Each Cartesian component obeys the same one-dimensional relation when its acceleration component is constant.

Output: v_x=u_x+a_x t; v_y=u_y+a_y t; Delta x=u_x t+0.5a_x t^2; Delta y=u_y t+0.5a_y t^2

K2D2-3 · VERIFY

If one axis determines an event time, reuse that same time on the other axis before recombining and checking the plane state.

Why valid: The event occurs once for the object; a time obtained from one component is the clock value for every component at that same event.

Output: event time transferred across axes, then one checked plane state

Worked conceptual anchor / exit

A particle starts with u=(0,5) m/s and constant a=(10,4) m/s². Set up the x and y position equations at common time t without solving a particular numerical t.

Model response: Use Delta x=0*t+0.5(10)t² and Delta y=5t+0.5(4)t² with the same t.

Plausible wrong path

The magnitude of acceleration should be inserted unchanged into both x and y equations.

Diagnose: If a=(10 i + 4 j) m/s², should both component equations use a=√116?

Repair: No. Use a_x=10 only in the x equation and a_y=4 only in the y equation; the magnitude is not either component.

Independent check / boundary

If a_y changes with time while a_x stays constant, may the constant-acceleration equations still be exact on both axes for the whole interval?

No. The x relation may remain exact, but the y constant-acceleration relation is not exact over that interval. — Model validity is checked per component.

CANONICALMEDIUM

Select the gravity-only projectile model before using projectile consequences

Entry assumptions: Can solve 2D constant-acceleration component equations. · If an oblique launch angle is given, angle-based vector decomposition is available as a separate prerequisite for that question.

Inferential jump: After release in the ideal near-Earth model, projectile motion is not a new set of laws: it is the same component kinematics with a_x=0 and a_y=-g (for +y upward).

Model gate: use the canonical projectile specialization only while its assumptions remain true.

Completed construction

K2D3-1 · DECLARE

Decide whether the object is in ideal near-Earth free flight after release; neglect air resistance, declare +y, then set a_x=0 and a_y=-g.

Why valid: The standard projectile equations are a conditional specialization of 2D constant acceleration, not an automatic label for every launched object.

Output: gravity-only projectile acceleration state

K2D3-2 · TRANSFORM

Use supplied or separately resolved u_x and u_y with one common t in the horizontal and vertical component equations.

Why valid: Horizontal, oblique and downward/upward initial components change the initial state, not the gravity-only model.

Output: v_x=u_x; v_y=u_y-g t; Delta x=u_x t; Delta y=u_y t-0.5g t^2

K2D3-3 · DECLARE

Translate the requested event into the component condition that defines it before solving for time.

Why valid: Apex, same-height return, ground impact and a specified later instant are different events; each is identified by a different component condition.

Output: event condition chosen before calculation

K2D3-4 · TRANSFORM

For an apex event, set v_y=0 while keeping v_x=u_x and a_y=-g.

Why valid: At the highest point only the vertical velocity component is momentarily zero; gravity still accelerates downward and horizontal motion continues.

Output: apex condition v_y=0 with nonzero horizontal velocity and nonzero downward acceleration

K2D3-5 · TRANSFORM

For a return to the launch height, set Delta y=0 and treat any same-height flight-time/range shortcut as conditional on that equality.

Why valid: The shortcut follows from the vertical displacement returning to its initial value; it is not valid when the landing height differs.

Output: same-height event condition and its validity boundary

K2D3-6 · TRANSFORM

For any unequal-height landing, use the actual Delta y=y_f-y_i in the vertical position equation and retain the actual u_y; for a horizontal launch specifically, set u_y=0, then obtain the event time vertically and share it with x.

Why valid: Initial vertical velocity and landing displacement describe different facts. The landing event is fixed by the actual vertical geometry, while u_y=0 is only the horizontal-launch initial condition.

Output: Delta y=y_f-y_i=u_y t_event-0.5g t_event^2; for horizontal launch u_y=0; reuse the solved t_event on x

K2D3-7 · VERIFY

At the selected event time, reconstruct the requested velocity, speed, direction, displacement or range from simultaneous components and check qualitative limits.

Why valid: The reported projectile result is a consequence of one component model and one event, so its components must refer to the same instant and satisfy a_x=0, a_y=-g.

Output: checked projectile consequence at one physical event

Worked conceptual anchor / exit

A stone is launched horizontally from a cliff with speed u. With +y upward and air resistance neglected, write its component acceleration, velocity and displacement relations after release and explain why one common t is used.

Model response: a_x=0, a_y=-g; v_x=u, v_y=-gt; Delta x=ut, Delta y=-0.5gt², all at the same elapsed time t.

Plausible wrong path

A projectile needs a horizontal force to keep moving horizontally.

Diagnose: If a_x=0 after release, can v_x still be nonzero?

Repair: Yes. Zero horizontal acceleration means horizontal velocity stays constant, not that it becomes zero.

Independent check / boundary

A launched object continues under significant horizontal thrust after release. May the standard a_x=0 projectile specialization be used?

No. The object is not in gravity-only free flight; its horizontal acceleration is not zero under that model. — Projectile equations are conditional consequences of a declared force/model state.

Extension teaching

EXTENSIONHARD

EXTENSION — instantaneous velocity direction from x(t) and y(t)

Entry assumptions: Can interpret x(t) and y(t) as one particle with one shared time. · Has introductory meaning of derivative as instantaneous rate of change.

Inferential jump: The direction of motion at an instant comes from the tangent velocity (dx/dt, dy/dt), not from the position vector (x,y).

Shared-clock representation: component values form one state only when they refer to the same instant.

Completed construction

K2DX1-1 · DECLARE

Identify that the requested direction is the direction of instantaneous velocity, not the direction from the origin to the particle.

Why valid: Velocity is the instantaneous rate of change of position; position direction answers a different question.

Output: target vector is v(t)

K2DX1-2 · TRANSFORM

Differentiate x(t) and y(t) separately to obtain v_x(t) and v_y(t).

Why valid: Cartesian component derivatives give the components of the velocity vector.

Output: v_x=dx/dt and v_y=dy/dt

K2DX1-3 · TRANSFORM

Evaluate both velocity components at the same requested time and use their signed ratio to determine the direction.

Why valid: The two components form one simultaneous velocity vector only at the same instant.

Output: tan(theta)=v_y/v_x with quadrant checked

K2DX1-4 · VERIFY

Compare the velocity arrow with the local tangent to the trajectory and reject any answer based only on y/x.

Why valid: Instantaneous velocity is tangent to the path while the position vector generally is not.

Output: direction passes the tangent check

Worked conceptual anchor / exit

If x=5t and y=12t-t^2, state the operations needed to find the velocity direction at t=2 s.

Model response: Differentiate to get v_x=5 and v_y=12-2t, evaluate both at t=2, then use the signed component ratio and quadrant.

Plausible wrong path

Use y/x at the requested time to get the direction of motion.

Diagnose: Does y/x describe the tangent direction or only the direction of the position vector from the origin?

Repair: Differentiate first; use v_y/v_x for the velocity direction.

Independent check / boundary

If x and y are both nonzero but v_y=0, is the velocity horizontal?

Yes. Position direction may be slanted while the instantaneous velocity is horizontal. — Position direction and velocity direction are distinct.

EXTENSIONHARD

EXTENSION — projectile rebound after an energy-changing impact

Entry assumptions: Can use the gravity-only projectile maximum-height relation after launch. · Can resolve a speed into components.

Inferential jump: A stated kinetic-energy retention fraction acts on v^2; after the collision creates a new launch state, only that new vertical component controls the next rise height.

Model gate: use the canonical projectile specialization only while its assumptions remain true.

Completed construction

K2DX2-1 · DECLARE

Treat impact as an event boundary: pre-impact projectile flight ends and a new post-impact launch state begins.

Why valid: An impulsive collision changes velocity over a short event and the next free-flight segment starts from the post-impact state.

Output: post-impact launch state

K2DX2-2 · TRANSFORM

Convert K_after=f K_before into v_after^2=f v_before^2 for unchanged mass.

Why valid: K=1/2 mv^2, so an energy fraction multiplies speed squared.

Output: v_after^2=f v_before^2

K2DX2-3 · TRANSFORM

Resolve the post-bounce speed using its stated direction and use the upward component in H=v_y^2/(2g).

Why valid: Maximum rise after the bounce depends on the post-bounce vertical kinetic state under gravity-only flight.

Output: H_after=(v_after sin alpha)^2/(2g)

K2DX2-4 · VERIFY

Check that losing energy cannot create a rebound height inconsistent with the retained-energy fraction and vertical-component fraction.

Why valid: Energy and component fractions provide an independent bound on the height.

Output: height scaling is physically bounded

Worked conceptual anchor / exit

A ball keeps 64% of its kinetic energy and rebounds at an angle alpha. State the chain needed to find its new maximum height.

Model response: Use v_after^2=0.64 v_before^2, take v_y=v_after sin alpha, then H=v_y^2/(2g).

Plausible wrong path

If half the kinetic energy remains, the speed becomes half.

Diagnose: If K is proportional to v squared, what speed-squared fraction corresponds to a 50% energy retention?

Repair: The speed squared becomes one half; the speed becomes 1/sqrt(2) of its previous value.

Independent check / boundary

If the ball rebounds horizontally, can it gain height immediately after the collision under gravity alone?

No. Its post-bounce vertical component is zero, so the next rise height is zero. — The post-impact vertical component, not total speed, sets maximum rise.

EXTENSIONHARD

EXTENSION — projectile motion when gravity changes after the apex

Entry assumptions: Can identify the apex by v_y=0. · Can solve vertical constant-acceleration motion from a known state.

Inferential jump: A change in constant gravity creates two kinematic stages joined by one boundary state; position and velocity at the apex are inherited by the second stage while acceleration changes.

Event-clock representation: preserve the boundary state, then apply the law valid on the next interval.

Completed construction

K2DX3-1 · DECLARE

Split the trajectory at the apex boundary and label stage 1 with g_1 and stage 2 with g_2.

Why valid: The model assumption changes at one event, so one constant-acceleration equation cannot span both regions.

Output: two-stage event model

K2DX3-2 · TRANSFORM

Use the ordinary projectile model only up to the apex to determine the apex position and horizontal velocity.

Why valid: Before the boundary, gravity is g_1 and horizontal acceleration is zero.

Output: apex state (x_A,H,v_x,0)

K2DX3-3 · TRANSFORM

Start stage 2 from the apex with v_y=0 and downward acceleration g_2; compute the descent time from H=(1/2)g_2 t_2^2.

Why valid: The second stage is constant-acceleration motion with its own acceleration but inherited initial state.

Output: t_2=sqrt(2H/g_2)

K2DX3-4 · VERIFY

Check that increasing post-apex gravity shortens only the descent portion and therefore shortens only the post-apex horizontal distance.

Why valid: v_x remains unchanged at the boundary while the fall time changes.

Output: range ratio lies between apex fraction and ordinary full range for stronger gravity

Worked conceptual anchor / exit

If post-apex gravity is four times larger, how does the descent time from the same apex height compare with the ordinary descent time?

Model response: It is half as long because t is proportional to 1/sqrt(g) for a fall from rest through the same height.

Plausible wrong path

Once gravity changes at the apex, recompute the entire trajectory using the new gravity.

Diagnose: Did the projectile experience g_2 before it reached the apex?

Repair: No. Preserve the stage-1 apex state, then apply g_2 only to stage 2.

Independent check / boundary

If g_2 equals g_1, should the two-stage result reduce to the ordinary projectile result?

Yes. — The extension contains the standard model as a limiting case.

EXTENSIONHARD

EXTENSION — trajectory equation through a specified point

Entry assumptions: Can write x(t) and y(t) for a gravity-only projectile. · Can resolve an initial speed into horizontal and vertical components.

Inferential jump: Eliminating the common time creates a path equation y(x), but passing through a point and locating the apex are separate decisions.

Shared-clock representation: component values form one state only when they refer to the same instant.

Completed construction

K2DX4-1 · DECLARE

Confirm the gravity-only projectile assumptions before eliminating time.

Why valid: The trajectory equation is a consequence of the standard projectile model, not a universal curve.

Output: projectile model licensed

K2DX4-2 · TRANSFORM

Use x=u cos(theta)t to eliminate t from y=u sin(theta)t-(1/2)gt^2.

Why valid: Both component equations describe the same event time, so eliminating that common t is valid.

Output: y=x tan(theta)-g x^2/[2u^2 cos^2(theta)]

K2DX4-3 · TRANSFORM

Substitute the specified point coordinates to constrain u and theta.

Why valid: A point lies on the trajectory only if its coordinates satisfy the path equation.

Output: point constraint on launch parameters

K2DX4-4 · VERIFY

Use v_y at the point or the local trajectory slope to decide whether the projectile is rising or falling there.

Why valid: Passing through P does not by itself reveal whether P occurs before or after the apex.

Output: apex-relative position classified

Worked conceptual anchor / exit

What two checks are needed when asked whether a projectile passes through P and has already crossed its apex there?

Model response: First impose P in the trajectory equation; then use v_y or local slope at P to determine whether the path is descending.

Plausible wrong path

If a point satisfies the trajectory equation, the apex must be after that point.

Diagnose: Can a projectile pass through the same height on both its rising and falling branches?

Repair: Yes. Use v_y or slope at the point to determine the branch.

Independent check / boundary

If tan(theta)=y_P/x_P exactly, can a finite-speed gravity-only projectile launched from the origin pass through P above the straight launch ray?

No. Gravity lowers the path below the straight-line term for any finite speed. — The gravity term imposes a physical reachability constraint.

EXTENSIONHARD

EXTENSION — projectile motion with linear drag

Entry assumptions: Can apply Newton's second law to one component. · Understands an exponential decay law at a qualitative level or can follow its supplied solution.

Inferential jump: With F_drag=-cv, horizontal acceleration is proportional to -v_x rather than zero; solving the differential equation gives exponential velocity decay and displacement must be integrated from that velocity.

Model gate: use the canonical projectile specialization only while its assumptions remain true.

Completed construction

K2DX5-1 · DECLARE

Reject the standard a_x=0 projectile specialization when linear drag F=-cv is retained.

Why valid: Drag has a horizontal component whenever v_x is nonzero, so horizontal acceleration is not zero.

Output: modified horizontal model selected

K2DX5-2 · TRANSFORM

Write Newton's second law in x: m dv_x/dt=-c v_x.

Why valid: Linear drag opposes the instantaneous velocity and is proportional to its component.

Output: dv_x/dt=-(c/m)v_x

K2DX5-3 · TRANSFORM

Use the exponential solution v_x(t)=v_x0 exp(-ct/m) and integrate it over time.

Why valid: The first-order decay equation has an exponential solution; displacement is the time integral of velocity.

Output: x-x_0=(m/c)v_x0[1-exp(-ct/m)]

K2DX5-4 · VERIFY

Check that c→0 recovers x-x_0≈v_x0 t and that drag distance is smaller than the no-drag distance for c>0.

Why valid: The limiting model and inequality provide independent checks.

Output: solution recovers no-drag limit and reduced range

Worked conceptual anchor / exit

For m dv_x/dt=-c v_x, state v_x(t), the horizontal displacement from 0 to t, and one limiting check.

Model response: v_x=v_x0 e^{-ct/m}; Δx=(m/c)v_x0(1-e^{-ct/m}); as c approaches zero, Δx approaches v_x0 t.

Plausible wrong path

Use x=v_x0 t because projectile horizontal velocity is always constant.

Diagnose: If the drag force has an x component -c v_x, can a_x still be zero?

Repair: No. Solve the velocity-dependent equation first, then integrate v_x(t).

Independent check / boundary

If c is extremely small, what should the drag result resemble?

The ordinary no-drag horizontal motion x≈v_x0 t. — The modified model joins smoothly to the canonical model.
