CANONICAL

Split one plane-motion event into independent x/y components with one clock

PREDICT

If x and y components are independent, does that mean the object has two different clocks?

RECONSTRUCT

Ask: What must be declared before any component can have a sign?

Recovers the common frame and axis convention.

Ask: What separates between axes, and what must stay common because both descriptions belong to one event?

Distinguishes component independence from the shared-clock invariant.

Ask: Which x and y values may be recombined into one state?

Makes simultaneity observable rather than implicit.

DIAGNOSE → REPAIR

Wrong idea: Independent x and y motions may use different elapsed times.

Diagnostic: At one instant 2 s after launch, may the x equation use t=2 s while the y equation uses another time?

Repair: No. Independence separates the axis equations; it does not give the same object two clocks.

BOUNDARY TEST

If a_x=0 but a_y is nonzero, may v_x stay constant while v_y changes?

Answer: Yes. That is exactly what independent component evolution permits.

MODEL RESPONSE

No. The component equations are separate, but the event uses one common elapsed time.

Rejoin: Perpendicular components may be solved separately because each axis equation contains only that axis's quantities, but they still describe one object at one physical time.

CANONICAL

Apply constant-acceleration kinematics component by component

PREDICT

If a_x is nonzero and a_y is zero, which velocity component changes with time?

RECONSTRUCT

Ask: Before using a constant-acceleration formula, what must be true about that axis's acceleration component?

Makes model validity explicit rather than formula-driven.

Ask: What does the 1D relation become when written only along x, and what changes for y?

Transfers an existing model one axis at a time.

Ask: If one component equation finds the event time, what time must the other component use?

Recovers the shared-clock coupling at an event.

DIAGNOSE → REPAIR

Wrong idea: The magnitude of acceleration should be inserted unchanged into both x and y equations.

Diagnostic: If a=(10 i + 4 j) m/s², should both component equations use a=√116?

Repair: No. Use a_x=10 only in the x equation and a_y=4 only in the y equation; the magnitude is not either component.

BOUNDARY TEST

If a_y changes with time while a_x stays constant, may the constant-acceleration equations still be exact on both axes for the whole interval?

Answer: No. The x relation may remain exact, but the y constant-acceleration relation is not exact over that interval.

MODEL RESPONSE

Only v_x changes; v_y remains constant.

Rejoin: The one-dimensional constant-acceleration equations can be applied to each perpendicular component independently when a_x and a_y are each constant over the same interval.

CANONICAL

Select the gravity-only projectile model before using projectile consequences

PREDICT

Immediately after a horizontal launch, which acceleration component is zero in the ideal model?

RECONSTRUCT

Ask: What forces remain after release in the idealized problem?

Elicits the gravity-only model.

Ask: What are the horizontal and vertical component equations, and what clock do they share?

Rebuilds the projectile specialization from 2D constant acceleration.

Ask: What exact component condition identifies the event the question asks about?

Separates model selection from event selection.

Ask: If the event is the apex, what becomes zero and what definitely does not?

Protects against the common full-velocity/full-acceleration zero shortcut.

Ask: Does launch height equal landing height? If not, which shortcut becomes invalid?

Makes the same-height boundary explicit.

DIAGNOSE → REPAIR

Wrong idea: A projectile needs a horizontal force to keep moving horizontally.

Diagnostic: If a_x=0 after release, can v_x still be nonzero?

Repair: Yes. Zero horizontal acceleration means horizontal velocity stays constant, not that it becomes zero.

BOUNDARY TEST

A launched object continues under significant horizontal thrust after release. May the standard a_x=0 projectile specialization be used?

Answer: No. The object is not in gravity-only free flight; its horizontal acceleration is not zero under that model.

MODEL RESPONSE

a_x is zero; a_y is -g if +y is upward.

Rejoin: After release in the ideal near-Earth model, projectile motion is not a new set of laws: it is the same component kinematics with a_x=0 and a_y=-g (for +y upward).

EXTENSION — instantaneous velocity direction from x(t) and y(t)

PREDICT

At t=2 s, should a direction question use y/x or (dy/dt)/(dx/dt)?

RECONSTRUCT

Ask: What vector's direction is requested?

Prevents position/velocity confusion.

Ask: How do x(t) and y(t) become velocity components?

Recovers the derivative bridge.

Ask: Which time must both components use?

Preserves the shared clock.

DIAGNOSE → REPAIR

Wrong idea: Use y/x at the requested time to get the direction of motion.

Diagnostic: Does y/x describe the tangent direction or only the direction of the position vector from the origin?

Repair: Differentiate first; use v_y/v_x for the velocity direction.

BOUNDARY TEST

If x and y are both nonzero but v_y=0, is the velocity horizontal?

Answer: Yes. Position direction may be slanted while the instantaneous velocity is horizontal.

MODEL RESPONSE

Use (dy/dt)/(dx/dt) because the question asks for instantaneous velocity direction.

Rejoin: The direction of motion at an instant comes from the tangent velocity (dx/dt, dy/dt), not from the position vector (x,y).

EXTENSION — projectile rebound after an energy-changing impact

PREDICT

If a collision leaves 50% of kinetic energy, does the post-collision speed become 50%?

RECONSTRUCT

Ask: What state begins the second flight?

Separates the collision event from free flight.

Ask: What quantity is proportional to kinetic energy for fixed mass?

Prevents the half-energy/half-speed error.

Ask: Which post-bounce component controls height?

Reconnects to the canonical projectile model.

DIAGNOSE → REPAIR

Wrong idea: If half the kinetic energy remains, the speed becomes half.

Diagnostic: If K is proportional to v squared, what speed-squared fraction corresponds to a 50% energy retention?

Repair: The speed squared becomes one half; the speed becomes 1/sqrt(2) of its previous value.

BOUNDARY TEST

If the ball rebounds horizontally, can it gain height immediately after the collision under gravity alone?

Answer: No. Its post-bounce vertical component is zero, so the next rise height is zero.

MODEL RESPONSE

No. Its speed squared becomes 50%, so speed scales by the square root.

Rejoin: A stated kinetic-energy retention fraction acts on v^2; after the collision creates a new launch state, only that new vertical component controls the next rise height.

EXTENSION — projectile motion when gravity changes after the apex

PREDICT

When gravity changes only after the apex, which parts of the state must be carried across unchanged?

RECONSTRUCT

Ask: Where does the model change?

Defines the event boundary.

Ask: What state is continuous across that boundary?

Prevents recomputing stage 1.

Ask: Which equation determines the new descent time?

Reconnects to constant acceleration.

DIAGNOSE → REPAIR

Wrong idea: Once gravity changes at the apex, recompute the entire trajectory using the new gravity.

Diagnostic: Did the projectile experience g_2 before it reached the apex?

Repair: No. Preserve the stage-1 apex state, then apply g_2 only to stage 2.

BOUNDARY TEST

If g_2 equals g_1, should the two-stage result reduce to the ordinary projectile result?

Answer: Yes.

MODEL RESPONSE

The apex position and velocity are continuous; the acceleration law changes after the boundary.

Rejoin: A change in constant gravity creates two kinematic stages joined by one boundary state; position and velocity at the apex are inherited by the second stage while acceleration changes.

Does substituting a point into y(x) alone tell you whether the projectile is rising or falling there?

RECONSTRUCT

DIAGNOSE → REPAIR

Wrong idea: If a point satisfies the trajectory equation, the apex must be after that point.

Diagnostic: Can a projectile pass through the same height on both its rising and falling branches?

Repair: Yes. Use v_y or slope at the point to determine the branch.

BOUNDARY TEST

If tan(theta)=y_P/x_P exactly, can a finite-speed gravity-only projectile launched from the origin pass through P above the straight launch ray?

Answer: No. Gravity lowers the path below the straight-line term for any finite speed.

MODEL RESPONSE

No. It shows the point is on the path; a velocity or slope sign is still needed.

Rejoin: Eliminating the common time creates a path equation y(x), but passing through a point and locating the apex are separate decisions.

EXTENSION — projectile motion with linear drag

PREDICT

If drag is proportional to velocity, may you still use the ordinary constant-horizontal-velocity projectile shortcut?

RECONSTRUCT

Ask: Which standard projectile assumption fails?

Makes model choice explicit.

Ask: What equation replaces a_x=0?

Links force to changing velocity.

Ask: How does velocity become displacement?

Prevents multiplying final velocity by time.

DIAGNOSE → REPAIR

Wrong idea: Use x=v_x0 t because projectile horizontal velocity is always constant.

Diagnostic: If the drag force has an x component -c v_x, can a_x still be zero?

Repair: No. Solve the velocity-dependent equation first, then integrate v_x(t).

BOUNDARY TEST

If c is extremely small, what should the drag result resemble?

Answer: The ordinary no-drag horizontal motion x≈v_x0 t.

MODEL RESPONSE

No. Drag makes a_x depend on v_x, so horizontal velocity decays.

Rejoin: With F_drag=-cv, horizontal acceleration is proportional to -v_x rather than zero; solving the differential equation gives exponential velocity decay and displacement must be integrated from that velocity.
