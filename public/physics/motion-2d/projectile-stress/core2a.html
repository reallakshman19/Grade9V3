CORE2A · Supported application

Three-item diagnostic plus five learner-eligible authored twins with scaffolds, reasoning routes, cruxes, checks, and closure.

Start diagnostic · 3 items

Default starting coordinate: 50% familiarity, full support. Support changes only from actual attempts.

  1. At a projectile apex, which of v_x, v_y, and a_y is zero?
  2. If x(t) and y(t) describe one particle, may x(2 s) be paired with y(3 s) for one position?
  3. A launched object experiences significant horizontal drag. Is a_x=0 still valid?
Diagnostic criteria

1: only v_y is zero. 2: no, one state needs one time. 3: no, the standard projectile horizontal model is not valid under drag.

AUTHORED_PRACTICE

Q-PHY-KIN-2D-EXT-2A-VELOCITY-DIRECTION

A particle has x(t)=10t and y(t)=18t-2t^2 in metres. Find the direction of its instantaneous velocity at t=2 s.

Shared-clock representation: component values form one state only when they refer to the same instant.

Authored scaffolds + full reasoning route

REPRESENT: Write the representation or event boundary explicitly before substituting values.

  1. REPRESENT — Identify velocity direction as the target and write v_x=dx/dt, v_y=dy/dt. Instantaneous velocity is the derivative of position.
  2. TRANSFORM — Differentiate and evaluate both components at t=2 s. Both belong to the same instant.
  3. CONNECT — Use the signed velocity-component ratio to obtain the direction. A vector direction follows from its components.
  4. VERIFY — Confirm the arrow is tangent to the trajectory. Velocity must be tangent.

Application crux: R-EXT-2A-VEL-REP

Solution: The velocity components at 2 s are (10,10) m/s, so the direction is 45° above +x.

Check: The position ratio y/x is not used; the tangent/velocity check gives 45°.

Exposure: CORE2A · familiar application after teaching.

Q-PHY-KIN-2D-EXT-2A-BOUNCE

A projectile launched at 45° reaches 80 m maximum height. On returning to the ground it retains 60% of its kinetic energy and rebounds at 30° above horizontal. Find its new maximum height.

Shared-clock representation: component values form one state only when they refer to the same instant.

Authored scaffolds + full reasoning route

REPRESENT: Write the representation or event boundary explicitly before substituting values.

  1. REPRESENT — Mark impact as a new launch event and separate pre/post states. The collision changes velocity discontinuously.
  2. DECIDE — Convert retained kinetic energy into retained speed squared before resolving the new angle. K is proportional to v squared for fixed mass.
  3. TRANSFORM — Resolve post-bounce vertical speed and compute rise height. Gravity-only height uses v_y²/(2g).
  4. VERIFY — Check energy/component scaling bounds. Loss and smaller vertical fraction must reduce height.

Application crux: R-EXT-2A-BOUNCE-ENERGY

Solution: The new maximum height is 24 m.

Check: The result is below the original height and scales with retained energy and sin²30°.

Exposure: CORE2A · familiar application after teaching.

Q-PHY-KIN-2D-EXT-2A-PIECEWISE-G

An ordinary projectile would have range R. At the apex it enters a region where downward gravity becomes 4g while horizontal velocity is unchanged. Express the new range as a fraction of R.

Event-clock representation: preserve the boundary state, then apply the law valid on the next interval.

Authored scaffolds + full reasoning route

REPRESENT: Write the representation or event boundary explicitly before substituting values.

  1. REPRESENT — Split the event at the apex and carry the apex state into stage 2. The model changes only there.
  2. DECIDE — Apply 4g only to the post-apex descent. The first stage already occurred under g.
  3. TRANSFORM — Convert the time ratio into horizontal distance and add stage distances. Horizontal speed is continuous.
  4. VERIFY — Bound the result between R/2 and R. Only post-apex range shrinks.

Application crux: R-EXT-2A-G-DECIDE

Solution: The new range is 3R/4.

Check: The result lies between R/2 and R because stronger gravity changes only the descent segment.

Exposure: CORE2A · familiar application after teaching.

Q-PHY-KIN-2D-EXT-2A-POINT

A projectile launched at 45° passes through P=(4 m,1 m). Find u²/g and decide whether the projectile is rising or falling at P.

Shared-clock representation: component values form one state only when they refer to the same instant.

Authored scaffolds + full reasoning route

REPRESENT: Write the representation or event boundary explicitly before substituting values.

  1. REPRESENT — License the ideal projectile trajectory and mark P on x-y axes. The path relation requires the gravity-only model.
  2. TRANSFORM — Substitute P into y=x tanθ-gx²/[2u²cos²θ]. Point membership imposes a launch-parameter constraint.
  3. DECIDE — Use local slope or vertical velocity at P to decide the branch. Point membership alone does not identify rising/falling.
  4. VERIFY — Substitute back and confirm the slope sign. Independent substitution closes both decisions.

Application crux: R-EXT-2A-POINT-BRANCH

Solution: u²/g=16/3 m and the projectile is already descending at P.

Check: Substituting u²/g=16/3 back into the path gives y=1 and the negative slope locates P after the apex.

Exposure: CORE2A · familiar application after teaching.

Q-PHY-KIN-2D-EXT-2A-DRAG

A projectile has horizontal launch component 120 m/s. In a medium with linear drag, m/c=2 s. Find its horizontal displacement after 2 s using e≈2.718.

Event-clock representation: preserve the boundary state, then apply the law valid on the next interval.

Authored scaffolds + full reasoning route

REPRESENT: Write the representation or event boundary explicitly before substituting values.

  1. REPRESENT — Reject constant horizontal velocity and write the linear-drag horizontal law. Drag acts against v_x.
  2. DECIDE — Use exponential velocity decay rather than a constant-acceleration formula. Acceleration depends on velocity.
  3. TRANSFORM — Integrate v_x over 0 to 2 s. Displacement is the integral of velocity.
  4. VERIFY — Compare with v_x0 t. Drag must reduce distance.

Application crux: R-EXT-2A-DRAG-SOLVE

Solution: The displacement is about 152 m.

Check: The distance is less than the no-drag value 240 m and approaches it as c→0.

Exposure: CORE2A · familiar application after teaching.
