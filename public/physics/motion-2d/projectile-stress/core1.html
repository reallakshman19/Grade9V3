CORE1 · Orientation

Compact semantic orientation: canonical R1–R3 first, then labelled extensions and the five-question demand map.

Canonical orientation

One plane-motion event uses one frame and one clock. Apply constant-acceleration equations component by component only when each component acceleration is constant. For a standard projectile, choose the gravity-only model before using apex, range, height, or flight consequences.

Shared-clock representation: component values form one state only when they refer to the same instant.

Canonical R1–R3

R1CANONICAL

Split one plane-motion event into independent x/y components with one clock

Inferential jump: Perpendicular components may be solved separately because each axis equation contains only that axis's quantities, but they still describe one object at one physical time.

Intrinsic demand: MEDIUM — Learners often interpret independent components as unrelated motions and accidentally use different times or mix x and y quantities.

R2CANONICAL

Apply constant-acceleration kinematics component by component

Inferential jump: The one-dimensional constant-acceleration equations can be applied to each perpendicular component independently when a_x and a_y are each constant over the same interval.

Intrinsic demand: MEDIUM — The formulas are familiar from 1D, but the challenge is selecting the right component equation on each axis and enforcing one common time.

R3CANONICAL

Select the gravity-only projectile model before using projectile consequences

Inferential jump: After release in the ideal near-Earth model, projectile motion is not a new set of laws: it is the same component kinematics with a_x=0 and a_y=-g (for +y upward).

Intrinsic demand: MEDIUM — Projectile formulas become brittle when the learner skips the model decision, mixes times, or treats horizontal velocity as requiring a continuing horizontal force.

Demand extensions, after R1–R3

E1EXTENSION

EXTENSION — instantaneous velocity direction from x(t) and y(t)

Inferential jump: The direction of motion at an instant comes from the tangent velocity (dx/dt, dy/dt), not from the position vector (x,y).

Intrinsic demand: HARD — The hard decision is distinguishing position direction from the tangent/velocity direction and differentiating both component functions at the same instant.

E2EXTENSION

EXTENSION — projectile rebound after an energy-changing impact

Inferential jump: A stated kinetic-energy retention fraction acts on v^2; after the collision creates a new launch state, only that new vertical component controls the next rise height.

Intrinsic demand: HARD — The main trap is converting an energy fraction directly into a speed fraction instead of remembering K is proportional to v squared.

E3EXTENSION

EXTENSION — projectile motion when gravity changes after the apex

Inferential jump: A change in constant gravity creates two kinematic stages joined by one boundary state; position and velocity at the apex are inherited by the second stage while acceleration changes.

Intrinsic demand: HARD — The learner must preserve the apex state and change only the post-boundary acceleration law rather than recompute the whole flight under the new gravity.

E4EXTENSION

EXTENSION — trajectory equation through a specified point

Inferential jump: Eliminating the common time creates a path equation y(x), but passing through a point and locating the apex are separate decisions.

Intrinsic demand: HARD — The learner must eliminate time without losing the physical event interpretation, then use the sign of vertical velocity or local slope to locate the apex.

E5EXTENSION

EXTENSION — projectile motion with linear drag

Inferential jump: With F_drag=-cv, horizontal acceleration is proportional to -v_x rather than zero; solving the differential equation gives exponential velocity decay and displacement must be integrated from that velocity.

Intrinsic demand: HARD — The key model decision is recognizing that velocity-dependent drag makes acceleration non-constant, so the ordinary constant-acceleration projectile formulas no longer apply.
